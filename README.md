# Hunk customizations

My customizations for [Hunk](https://www.hunk.dev/).

- `graphite-theme` restores Hunk's retired Graphite palette.
- `export-notes` copies saved review notes to the clipboard as compact Markdown.

## Export notes usage

Use `[` or `]`, then `c`, to write a hunk note. `Ctrl-E` copies and asks whether to clear; `Ctrl-X` copies and clears without confirmation.

## Install

```sh
hunk extension install toommyliu/hunk-customizations
hunk extension install /path/to/hunk-customizations
```
